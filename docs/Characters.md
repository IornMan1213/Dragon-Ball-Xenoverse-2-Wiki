# Characters & Presets Unlock Overview

The roster is best treated as a database rather than a single unlock list. Characters, forms and special presets can originate from story progression, Parallel Quests, Shenron, DLC, events and other systems.

## Unlock Sources
1. **Main Story** — core roster progression and many early presets.
2. **Parallel Quests** — characters, alternate forms and rewards tied to mission completion and Ultimate Finish conditions.
3. **Shenron Wishes** — selected character unlocks and other progression rewards.
4. **DLC / Future Saga** — major groups of playable characters, forms and special presets.
5. **Partner Customization Keys** — Raid-related keys unlock additional customization options for selected partners.
6. **Special content** — Distorted Time Eggs/Unknown History, Festival/event content and other limited systems.

## Character Database Fields
The redesigned wiki will treat each character record as:

| Field | What it should contain |
|---|---|
| Character | Display name / form |
| Race | Saiyan, Earthling, Namekian, Majin, Frieza Race, Android, etc. |
| Preset | Costume/form/preset identifier when applicable |
| Unlock | Exact unlock path |
| DLC | Required pass/pack/chapter, if any |
| Skills | Notable equipped skills |
| Awoken | Transformation or powered state |
| Customization | Whether Partner Customization applies |
| Source | Story, PQ, wish, event, DLC, etc. |
| Verification | Confirmed / community / needs checking |

The external Fandom character category currently exposes a large roster index, including alternate forms and newer characters such as Goku (Mini), Cell Max, Orange Piccolo and newer Ultra Supervillain variants. Use it as a cross-check rather than blindly copying prose from individual pages.

## Useful Completion Route
For a “unlock everything” run, separate the checklist into **base-game roster**, **DLC roster**, **special/event presets**, and **Partner Customization**. This prevents a character that is technically unlocked from being mistaken for a character whose alternate preset or customization key is still missing.
