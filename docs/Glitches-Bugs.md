# Known Glitches, Bugs & Exploits

**Strong Warning**: Glitches can cause crashes, softlocks, save issues, or online bans. Prefer offline play. Information is community-reported and changes with patches. Always back up saves.

## Recent / Notable (2025–2026)
- **Infinite History / “Unwelcome Challenger” crash** (reported around July 2026): On Xbox and PC Game Pass versions, certain path choices can crash when Vegeta transforms. PlayStation versions were reported working. Different path selection or waiting for a patch are the main workarounds.
- Occasional post-update launch or online stability issues on Steam (usually resolved via official maintenance).

## Older / Persistent Mentions
- Item duplication methods involving gifting + cloud/USB restore (platform-dependent, ToS risk).
- Various offline trainers and Cheat Engine tables for infinite items, max stats, always Z-rank, Shenron anytime, etc. (PC only, version-matched tables required).
- Ultrawide support and FOV adjustments via community ASI plugins (requires non-EAC launch).

## General Advice
- Report new bugs through official Bandai channels or the Steam forums.
- For modding tools see the [Resources](Resources.md) page.
- This list is intentionally high-level. Check Reddit, ContonMods on X, and Discord communities for the absolute latest reports and reproduction steps.
