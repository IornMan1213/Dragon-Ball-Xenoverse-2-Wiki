# Known Glitches, Bugs & Exploits (As of mid-late 2026)

**Warning**: Using glitches can risk online bans, save corruption, or softlocks. Prefer offline/single-player. Many older glitches have been patched. Information is community-reported and may vary by platform/version.

## Recent / Platform-Specific Notes
- **Infinite History DLC / "Unwelcome Challenger" crash** (reported July 2026): On Xbox / Game Pass PC versions, choosing certain path ("Rivaled only by One") can crash when Vegeta transforms to Super Saiyan. PS versions reported working. Workarounds: different path or wait for patch.
- Online stability issues have occurred after major updates (e.g., launch failures on Steam after specific builds) — usually resolved via maintenance.

## Older / Persistent Community Mentions
- Item duplication via gift + cloud/USB restore (risky, platform dependent, may violate ToS).
- Various offline trainers / Cheat Engine tables exist for PC (infinite items, max stats, always Z-rank, etc.) — purely single-player and at your own risk. Search FearLess Revolution or similar communities for latest tables matching current version (e.g., 1.26+).
- Ultrawide / FOV fixes via community ASI plugins (e.g., DBXV2Fix on Codeberg) — requires launching without EAC.

## General Advice
- Always back up saves before experimenting.
- Report new bugs via official Bandai channels or Steam forums.
- For modding tools (LibXenoverse2, xv2patcher, character creators, etc.): See the Resources page. These are for single-player/offline use.

This list is incomplete by nature. Check Reddit (r/dbxv), ContonMods on X/Twitter, and Discord communities for the absolute latest reports.
