# Skills Database (Local Overview)

This page keeps core skill information **on-wiki** so users can reference acquisition methods and categories without leaving. Full exhaustive per-skill tables exist on Fandom; this wiki focuses on usable, sourced summaries and high-value data.

## Skill Categories
- **Super Attacks** (4 slots) — Strike or Ki Blast, buffs, utility.
- **Ultimate Attacks** (2 slots) — High damage finishers.
- **Evasive Skills** (1 slot) — Stamina-cost escapes, counters, or invincibility options.
- **Awoken Skills** (transformation slot) — Race-specific or universal power-ups (Super Saiyan line, Potential Unleashed, Beast, Power to Overcome, Golden, Purification, Giant, Power Pole Pro, Kaioken stages, Ultra Instinct, etc.).

## Primary Acquisition Methods (All Local)
1. **Mentor Lessons** — Guaranteed skills from each instructor’s four training missions.
2. **Parallel Quests** — Many skills listed as rewards; Ultimate Finish improves odds/quality.
3. **TP Medal Shop** — Rotating stock.
4. **Shenron Wishes** — Specific Super/Ultimate attacks via dedicated wishes.
5. **Crystal Raids / Double Crystal Raids** — Broad skill pool, useful for missing entries.
6. **DLC Extra Missions & PQs** — Exclusive skills from each pack/Future Saga chapter.
7. **Events / Festival of Universes** — Temporary or permanent skill rewards.

## Notable Awoken Skills (Summary)
- **Potential Unleashed** — Universal, obtained via Super Class Advancement Test after Z-ranking prior tests.
- **Beast** — Unlocked via Future Saga content / related missions.
- **The Power to Overcome** — Future Saga Chapter 4 story completion.
- Race exclusives: Super Saiyan line / Super Vegeta / SSG / SSB / SSB Evolved (Saiyan), Turn Golden (Frieza Race), Become Giant (Namekian), Purification (Majin), Power Pole Pro (Earthling).
- Kaioken stages and Ultra Instinct variants also available under specific conditions.

## High-Value / Meta Skills (Examples)
Community frequently highlights strong charge skills (Burst Charge, Ultimate Charge, etc.), stamina-break tools (Dodoria Headbutt, certain grabs), and high-damage Ultimates obtained from late PQs, mentors, or DLC. Exact current meta shifts with balance patches and new DLC.
