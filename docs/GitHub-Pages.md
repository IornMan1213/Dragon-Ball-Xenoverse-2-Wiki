# Turning This Repo into a Website (GitHub Pages)

This repository is already structured for easy conversion into a static site.

## Quick Setup
1. Go to the repository **Settings → Pages**.
2. Under “Source”, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)` or `/docs` depending on preference.
4. Save. GitHub will provide a `https://IornMan1213.github.io/Dragon-Ball-Xenoverse-2-Wiki/` URL (or similar).

## Optional Improvements
- Add a simple `index.md` or `index.html` that redirects to the README or a nicer landing page.
- Use a lightweight theme (e.g. via `_config.yml` for Jekyll) if you want navigation and styling.
- Keep the Markdown files in `/docs` as the main content.

Once enabled, the wiki becomes easily shareable as a website while remaining fully editable via Git.
