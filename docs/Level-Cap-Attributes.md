# Level Cap & Attribute Points

## Level Cap Progression (Historical → Current)
Default starts at **80**. Raised stepwise through Guru (Namekian Time Rift) and then Whis (food items purchased from Item Shop for 100,000 Zeni each):

| Cap | How to Unlock |
|-----|---------------|
| 80  | Default / early Guru |
| 85–99 | Repeated visits to Guru after reaching previous cap + Namekian Rift progress |
| 99 → 120 | Whis + Parfait |
| 120 → 140 | Whis + Tempura / Sushi (exact food varies by update) |
| 140 → 160 | Whis + further food (e.g. Octopus Ball era) |
| 160 → 180 | Further Whis training |
| **199** | Final raise associated with Future Saga Chapter 4 free update window (community confirmed July 2026) |

Level cap increases are **account-wide** (shared across all CaCs). Attribute point totals scale with level.

Approximate total attribute points available (from Fandom data, scaled upward with later caps):
- Level 80: ~332
- Level 99: ~375
- Level 120: ~422
- Level 140: ~467
- Level 160: ~512
- Level 180: ~557
- Level 199: significantly higher (community reports ~600 total points when none allocated)

## Attribute Caps Per Stat
- Default: 100 points per individual attribute
- After Guru “unlock potential”: 125
- After Whis (level 99+ path): up to 200 per stat

These per-stat raises are **per character** (must be done on each CaC).

## The Six Attributes
1. Health  
2. Max Ki  
3. Max Stamina  
4. Basic Attacks  
5. Strike Supers  
6. Ki Blast Supers  

Race, height, and weight affect base values and how effective each point is. Clothing and QQ Bangs add further +/– modifiers (commonly aiming for +5 in desired stats).

**Community resources**: Search Reddit for “Level 199 attribute” or “Ki Stamina spreadsheet” for the latest optimal distributions with neutral / +1 to +5 QQ Bangs.

## Practical Tips
- Reach the soft cap, talk to Guru/Whis promptly, then continue leveling.
- Tosok (near shops) can level you with Zeni (early) then TP Medals (later). High-score PQs + Super Souls that boost score are efficient.
- Always back up saves before major point redistribution experiments.
