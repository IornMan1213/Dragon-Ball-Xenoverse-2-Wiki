# Skill Catalog Expansion

This dataset is the first large population pass for the searchable skills database.

## Verification model

- `indexed`: the skill name/category is established by the source category taxonomy.
- `verified`: acquisition, costs, mechanics, or other detailed fields have been checked against an individual source page.

Indexed records are intentionally not presented as fully verified mechanics data.

## Current expansion

This pass adds a large batch of Strike Supers, Strike Ultimates, Evasives, Other Supers, Other Ultimates, and Power-Up skills to the searchable UI.

## Next passes

1. Populate the remaining Ki Blast Super and Ki Blast Ultimate records.
2. Populate all remaining race-specific and unavailable-for-CaC records.
3. Add acquisition methods, costs, users, DLC requirements, and descriptions from individual skill pages.
4. Deduplicate skills that appear in multiple taxonomy categories while retaining all source categories.
5. Add validation and generated catalog counts.
