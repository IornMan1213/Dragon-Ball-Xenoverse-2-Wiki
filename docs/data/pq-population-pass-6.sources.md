# PQ pass 6 source notes

Primary concrete data source used for this pass:

- `Madreag/xenoverse_2_wiki` PQ records, which document datamined DBXV2 TMQ/QXD quest tables and provide `lastVerified` / `asOfVersion` metadata.
- DBXV2 Fandom Parallel Quests index for category-level corroboration.

The external PQ collection describes the final game as having 183 standalone PQ missions, with numbering extending to 184 because PQ 36 was cut. That distinction is preserved in this repository instead of creating a false PQ 36 record.
