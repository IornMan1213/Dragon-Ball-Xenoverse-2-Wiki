## Reconciliation notes

The external datamined source describes exact reward percentages for the populated slice. Those percentages are retained where available, but the repository still treats the records as partially verified because the entire reward graph, quest unlock graph, and cross-domain references have not yet been mechanically reconciled against the local skill/equipment/Super Soul databases.

This conservative status is intentional: the project goal is exhaustive correctness, not the appearance of completeness.
