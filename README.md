
The repository is intentionally organized so that human-readable wiki pages, structured data, and maintenance scripts can evolve together. The project also includes automated data auditing and GitHub Actions workflows.

## 🛠️ Project Goals

The wiki aims to be:

- **Practical** — prioritize information players actually need in-game.
- **Sourced** — distinguish verified information from uncertain or community-reported details.
- **Searchable** — use predictable page names, headings, tables, and cross-links.
- **Maintainable** — keep repetitive data structured where useful and validate it automatically.
- **Community-friendly** — make corrections, additions, and new research easy to contribute.

## 🤝 Contributing

Found an incorrect unlock requirement? Missing DLC information? Have a better farming route or verified source?

See **[CONTRIBUTING.md](CONTRIBUTING.md)** for the contribution workflow and style rules.

For a focused change, open a pull request. For a larger idea or suspected problem, open an issue first.

## 🗓️ Current Focus

The project is in active expansion, with recent work focused on core systems, Super Souls, mentors, quests, farming information, and late-game/DLC coverage. The skill database is being expanded toward record-level coverage of every skill's effects and acquisition method, with the live explorer exposing individual research records while local verification catches up.
