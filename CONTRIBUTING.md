# Contributing to the Dragon Ball Xenoverse 2 Wiki

Thank you for helping expand this resource!

## How to Contribute
1. Fork the repository.
2. Create a new branch for your changes.
3. Edit or add Markdown files in `/docs` or the root.
4. Keep formatting clean and consistent (tables where useful, clear headings).
5. Open a Pull Request with a short description of what you added/fixed.

## Priority Areas
- Verified unlock conditions for newer DLC skills and Awoken Skills
- Accurate mentor reward lists (especially late DLC mentors)
- Level 199 attribute distribution math and optimal QQ Bang notes
- High-value Parallel Quest farming routes (2025–2026)
- Confirmed glitches/bugs with platform and version notes
- Links to new community spreadsheets or tools

## Style Guidelines
- Prefer factual, sourced information over speculation.
- Always note when something requires a specific DLC.
- Link to Fandom / dragonballxenoverse2.wiki / Reddit for deep tables rather than duplicating huge lists that will go stale.
- Use clear warnings on any glitch or exploit content.

## What Not to Do
- Do not encourage online cheating or ban-risking behavior without clear warnings.

Questions or big ideas? Open an Issue first.
